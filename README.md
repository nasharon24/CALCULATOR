# 🧮 Calculator System

A simple and responsive **Calculator Web Application** built using **HTML, CSS, and JavaScript**.  
This calculator can perform basic arithmetic operations such as addition, subtraction, multiplication, and division — designed with a clean user interface for easy use.

---

## 🚀 Features
- Basic operations: Addition, Subtraction, Multiplication, and Division  
- Clear and Delete functions  
- Real-time input and output display  
- Responsive design for both desktop and mobile  
- Lightweight and fast — no external libraries needed

---

## 🧩 Technologies Used
- **HTML** – Structure of the calculator  
- **CSS** – Styling and layout design  
- **JavaScript (script)** – Functional logic and interactivity
